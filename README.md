# TangTaMukei

Paper **26.3** 로비 플러그인 — Java 유저와 **Bedrock(GeyserMC)** 유저 모두 지원.

## 기능
- **허공 로비**: 빈 월드(`lobby`)를 만들고 공중에 떠 있는 원형 섬 로비를 자동 생성
  - 석영 무늬 바닥 + 아래쪽 바위 + 게임 포탈 아치 4개 + 벚나무 4그루 + 가로등
  - 가장자리 난간 + 투명 벽(배리어), 항상 낮·날씨 없음·몹 없음
- 접속하면 로비 스폰으로 이동 + 게임모드/체력/인벤토리 초기화 + 환영 타이틀·메시지·사운드
- 핫바 아이템: **게임 선택 나침반**, **플레이어 숨기기/보이기** 토글
- 게임 선택 메뉴
  - Java: 상자 GUI
  - Bedrock: Floodgate 가 있으면 **베드락 전용 버튼 폼**, 없으면 상자 GUI (Geyser 가 변환)
  - 메뉴 동작: `server:<이름>` (BungeeCord/Velocity 서버 이동), `command:<명령어>`, `message:<텍스트>`
- 로비 보호: 블록 파괴/설치, 데미지, 배고픔, 아이템 버리기/줍기, 인벤토리 이동 차단, 낙사 시 스폰 복귀
  - `tangtamukei.build` 권한 + 크리에이티브 모드면 보호 무시 (로비 꾸미기용)

## 팀 게임 (`/game start`)
- 접속자를 **레드 · 옐로우 · 그린 · 블루** 최대 4팀으로 랜덤 배정, 각 팀은 맵 꼭짓점에서 시작
  - 2팀이면 대각선 꼭짓점(레드·그린), 팀원끼리 공격 불가, 이름 색 표시
- 게임마다 새 맵: **16x16 청크(256x256)**, 맵 밖은 공허 + 월드보더
  - 맵 하나 만드는 데 약 2분 → 서버가 켜질 때와 게임이 끝날 때 **다음 맵을 로비 대기 중에 미리 만들어 둠**
  - 준비돼 있으면 `/game start` 즉시 시작, 준비 중이면 끝나는 대로 자동 시작
- **오려 붙인 야생 맵**: 숨겨진 일반 야생 월드에서 칸마다 맞는 바이옴·구조물을 찾아 블록 그대로 복사
  - 구조물 칸만 한 곳에서 이어서 가져옴 (작은 구조물 2x2 청크, 큰 구조물 4x4 청크)
  - 나머지는 **청크마다 각각 다른 곳**에서 가져와서 청크 경계마다 높낮이·지형이 뚝뚝 끊김
  - 상자·스포너 내용, 주민·몹도 함께 복사. 다른 곳에서 온 청크 사이로는 물·용암이 흐르지 않음 (물벽 유지)
- 2x2 청크 칸마다 바이옴 + 바닐라 구조물, 큰 구조물은 4x4 청크

```
 (x →)   0       1       2       3      4       5       6       7
 0     [레드]  야생(나무) 메사    ┌─── 마을 ───┐ 난파선  타이가  [옐로]
 1     타이가  야생(혼합) 사막    └────────────┘ 해저유적 벚꽃    숲
 2     난파선  해저유적 전초기지 대나무   늪   전초기지 사막    메사
 3     ┌ 해저 신전 ┐    늪     ┌─── 요새 ───┐ 대나무  ┌ 맨션 ─┐
 4     └──────────┘   대나무   └── (중앙) ──┘  늪    └───────┘
 5     메사     사막   전초기지  늪   대나무  전초기지 해저유적 난파선
 6     숲       벚꽃   해저유적 ┌─ 고대 도시 ─┐ 사막    벚꽃   타이가
 7     [블루]  타이가  난파선   └────────────┘ 메사     숲    [그린]
```
  - 구조물 자리는 비슷한 계열 바이옴 중 **사분면마다 다른 변형**이 나옴 (게임마다 섞임)
  - ★ 야생 자리(구조물 없는 일반 바이옴)는 **1청크마다 다른 바이옴** (4팀 모두 같은 구성으로 회전)

    | 자리 | 바이옴 변형 | 구조물 |
    |---|---|---|
    | 스폰 | 평원 · 해바라기 평원 · 초원 | |
    | 야생(나무) ★ | 숲 · 자작나무 · 꽃 숲 · 얼룩숲 · 거대 자작나무 · 어두운 숲 · 타이가 · 거대 가문비 · 바람 부는 숲 | |
    | 타이가 | 타이가 · 거대 가문비/소나무 타이가 · 눈 덮인 타이가 | 오래된 폐허 · 이글루 |
    | 야생(혼합) ★ | 벚꽃 숲(항상 2청크) + 초원 · 숲 지대 · 설원 · 얼음 가시 · 바람 부는 언덕 · 돌 봉우리 · 눈 덮인 비탈 · 해바라기 평원 · 사바나 · 듬성한 정글 · 자갈 언덕 (지하: 무성한 동굴) | |
    | 메사 | 악지 · 나무 악지 · 침식된 악지 (지하: 점적석 동굴) | 폐광 |
    | 사막 | 사막 (지하: 점적석 동굴) | 피라미드 |
    | 전초기지 | 사바나 · 사바나 고원 · 바람 부는 사바나 | 약탈자 전초기지 |
    | 대나무 | 대나무 정글 · 정글 · 듬성한 정글 (지하: 무성한 동굴) | 정글 사원 |
    | 늪 | 늪 · 맹그로브 늪 | 마녀 오두막 |
    | 바다 | 바다 · 따뜻한/미지근한/차가운 바다 | 난파선 · 해저 유적 |
    | 마을 | 평원 · 사바나 · 타이가 · 설원 · 사막 (게임마다 하나) | 마을 |
    | 맨션 | 어두운 숲 · 창백한 정원 | 삼림 대저택 |
    | 고대 도시 | 눈 덮인 타이가 · 숲 지대 · 얼음 가시 (지하: 깊은 어둠) | 고대 도시 |
    | 해저 신전 | 깊은 바다 · 깊은 미지근한/차가운 바다 | 해저 신전 |
    | 중앙 | 초원 · 평원 · 꽃 숲 | 요새 (엔드 포탈은 맵 정중앙) |
  - 4팀이 공평하도록 사분면 배치를 90도씩 회전, 큰 구조물은 두 팀 사이 변 가운데
- **네더**도 오버월드처럼 256x256, 칸마다 바이옴 지정 (진홍숲 · 영혼 모래 골짜기 · 현무암 삼각주 · 황무지)
  - 중앙은 **뒤틀린 숲** + **네더 요새** (요새가 맵 밖으로 안 나가는 시드를 미리 검사해서 고름)
  - 남북 변 가운데 보루, 폐허 포탈 · 네더 화석
  - **포탈은 1:1 좌표** (바닐라 8:1 무시)
- **엔드**도 게임마다 새로 생성, 월드보더는 메인 섬만 (300칸)
  - 드래곤을 잡아도 **엔드 게이트웨이가 생기지 않음**
  - 드래곤 처치 시 **(0, 80, 0)에 겉날개 상자** 생성
- 중앙 4x4 청크는 요새를 **엔드 포탈 방이 정중앙 (0, 0)에 오도록** 잘라서 가져옴
- 엔더의 눈은 그 포탈 방을 가리킴
- **땅따먹기**
  - 시작 꼭짓점 2x2 청크만 처음부터 그 팀 땅, 나머지는 주인 없는 땅
  - 주인 없는 땅에 들어가면 **시듦 255 + 허기 255**
  - 3칸 안에 주인 없는 땅이 있으면 그곳에 **빨간 색유리 낙하 블록 3x3** 표시 (본인에게만, 가까이 있는 동안 계속)
  - 발전과제를 깨면 부서지지 않는 철 도끼 **[일반 땅]** 지급 → 3칸 안의 주인 없는 땅을 바라보고 버리면(Q) 우리 팀 땅
  - **도전** 발전과제를 깨면 GUI로 선택 (베드락은 버튼 폼): [일반 땅] 5개 또는 **[특수 땅]** 1개
    - [특수 땅]: 부서지지 않는 네더라이트 도끼. 3칸 안의 **다른 팀 땅**을 바라보고 버리면 우리 땅으로 (주인 없는 땅은 불가)
    - 그냥 닫아도 "도전 보상 선택권"(네더의 별)을 우클릭하면 다시 열림
  - 다른 팀 땅은 우리 팀만 있는 상태로 5초 머물러도 빼앗을 수 있음 (두 팀 이상이면 경합으로 멈춤)
- **지도**: 시작할 때 모두에게 지급, `/map` 으로 다시 받기. 청크마다 바둑판으로 구분, 점령한 땅은 팀 색 + 팀원 위치는 팀 색 깃발
- **발전과제 진척 책**: `/book` 으로 받기 (베드락은 시작할 때 자동 지급). 펼칠 때·달성할 때마다 갱신
  - 게임 시작 때 이전 판 발전과제 진척 초기화 (`config.yml` 의 `game.reset-advancements`)
- `/game stop` 으로 종료하면 모두 로비로 돌아가고 게임 맵은 삭제

## 명령어
| 명령어 | 설명 | 권한 |
|---|---|---|
| `/lobby` (`/hub`, `/spawn`, `/로비`) | 로비로 이동 | 모두 |
| `/game start [팀수]` | 팀 게임 시작 (팀수 생략 시 인원수, 최대 4). 맵 준비 중이면 끝나는 대로 시작 | `tangtamukei.admin` |
| `/game status` | 맵 준비 상태 확인 | `tangtamukei.admin` |
| `/map` (`/지도`) | 땅따먹기 지도 받기 (게임 중) | 모두 |
| `/book` (`/책`) | 발전과제 진척 책 받기 | 모두 |
| `/game stop` | 게임 종료, 로비로 복귀 + 맵 삭제 후 다음 맵 준비 (대기 중이면 시작 취소) | `tangtamukei.admin` |
| `/lobbyrebuild` | 로비 구조물 다시 짓기 | `tangtamukei.admin` |
| `/setlobby` | 현재 위치를 로비 스폰으로 설정 | `tangtamukei.admin` |
| `/lobbyreload` | config.yml 다시 불러오기 | `tangtamukei.admin` |

## 빌드
Maven + Java 25 필요 (Paper 26.x 요구사항).
```
mvn package
```
결과물: `target/TangTaMukei-1.0.0.jar` → 서버 `plugins/` 폴더에 넣기.

## 설정
`plugins/TangTaMukei/config.yml` 에서 문구(MiniMessage), 아이템, 메뉴, 보호 옵션을 바꿀 수 있습니다.
